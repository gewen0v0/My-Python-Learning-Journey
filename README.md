三、代码说明
1. surf_a.py（长方体表面积计算）
核心是 surf_a() 函数，按公式 表面积 = 2×(长×宽 + 长×高 + 宽×高) 计算，调用时使用关键字参数，实参顺序更清晰：
def surf_a(x, y, z):
    print("长方体的长为：" + str(x) + "，宽为：" + str(y) + "，高为：" + str(z))
    s = 2 * (x * y + x * z + y * z)
    print("表面积为" + str(s))

surf_a(x=8, y=2, z=6)   # 关键字参数调用
程序演示了函数的定义（def）、形参的使用以及关键字传参的调用方式，运行后输出长宽高为 8、2、6 的长方体表面积 152。


2. fun_bmi.py（BMI 健康分类程序）
核心是 fun_bmi() 函数，按公式 BMI = 体重 / 身高² 计算指数，再用多个 if 分支按区间分类：
bmi = weight / (height * height)
if bmi < 18.5:
    print('体重过轻')
if bmi >= 18.5 and bmi < 24.9:
    print('正常范围')
if bmi >= 24.9 and bmi < 29.9:
    print('体重过重')
if bmi >= 29.9:
    print('肥胖')
程序用字符串拼接（+ 和 str()）输出信息，分别传入三组不同的身高体重数据调用函数，输出三人的 BMI 指数和对应的健康提示，演示了函数封装、算术运算与多分支条件判断的综合运用。
